# Weather-Tracker
This project's goal is to help predict future weather in the Grand Canyon from February 1st - 14th. It does this by getting historical data from the Mateo API, and displays the average temperature minimum and maximums for that period, in previous years. It also shows a forecast provided by Mateo.
This was built so you could see if the weather conditions in that time period were suitable for camping.
The data used is all from Mateo API.
